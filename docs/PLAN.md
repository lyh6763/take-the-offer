# TAKE THE OFFER — 기획서

> 제목: TAKE THE OFFER, 부제 "면접 리허설 작전". (처음 가제는 "면접 괴도단". 세계관 속 괴도단 설정은 그대로 둔다.)

> 압박 면접관의 왜곡된 마음을 훔쳐라.
> 실제로 면접 준비에 쓰는 도구를 괴도 작전처럼 연출한 웹앱. 페르소나 5의 스타일에서 모티브를 얻은 팬 스타일 작업이며, 원작사와 관계없다.

## 세계관

취준생들이 결성한 괴도단. 회사마다 압박 면접관의 마음속에 "팰리스"가 있다. 괴도단은 팰리스를 조사하고, 예고장을 보내고, 잠입해서 "합격"이라는 보물을 훔친다.

## 1단계 (첫 버전)

| 화면 | 하는 일 | 연출 |
| --- | --- | --- |
| 아지트 (홈) | 오늘 날짜, 다가오는 면접 D-day, 메뉴 | 날짜 컷, 사선으로 튀어나오는 메뉴 |
| 팰리스 | 지원 회사별 직무·면접일·인재상 키워드·예상 질문·메모, 침투 진행도 | 회사마다 팰리스 카드 |
| 예고장 | 입력한 문장을 오려 붙인 신문 글자 예고장으로 렌더, PNG 저장 | 글자마다 다른 종이·글꼴·기울기, 다시 섞기 |
| 잠입 | 모의 면접: 질문 낭독(음성 합성) → 답변 음성 인식(또는 직접 입력) → 분석 | 질문 카드 컷인, "약점 간파" |
| 총공격·결과 | 좋은 답변이면 총공격 컷인 → 결과 화면, 능력치 경험치 | 풀스크린 컷인, 결과 슬라이드 |
| 능력치 | 지식·담력·말솜씨·태도·매력 5종, 랭크 1~5 | 랭크업 연출 |
| 설정 | 모션 감소, 음성 켜기/끄기, 말 속도, 데이터 내보내기·가져오기·초기화 | — |

## 2단계

- 면접 배틀: 면접관의 질문을 적의 공격으로, 답변 전략(두괄식, STAR, 수치 근거, 역질문)을 스킬로 쓰는 턴제 전투
- 동료(스터디원) 시스템, 회사별 보스 면접관

## 답변 분석 (잠입)

- 답변 시간, 글자 수, 말 속도(분당 음절)
- 군말("음", "어", "그", "약간", "뭔가", "이제", "사실") 횟수
- 두괄식 여부(첫 문장에 결론 표현이 있는지)
- STAR 단서(상황·과제·행동·결과를 나타내는 표현), 수치 근거(숫자) 포함 여부
- 이 지표로 점수를 내고, 기준을 넘으면 총공격 컷인

모든 분석은 브라우저 안에서만 한다. 음성·답변은 서버로 보내지 않고 이 기기에만 저장한다. (음성 인식 자체는 브라우저 구현에 따라 브라우저 제조사 서버를 거칠 수 있으므로 화면에 안내한다.)

## 기술

- React 19 + TypeScript + Vite, 해시 라우팅(GitHub Pages)
- 상태: `useSyncExternalStore` 기반 작은 스토어 + localStorage 저장
- 연출: CSS 애니메이션·clip-path, View Transitions API(지원 브라우저), 모션 감소 시 페이드로 대체
- 음성: Web Speech API (SpeechSynthesis, SpeechRecognition — 지원 안 되면 텍스트 입력)
- 예고장: Canvas 2D로 미리보기와 PNG 저장을 같은 렌더러로
- 글꼴: Fontsource로 자체 호스팅(Black Han Sans, Do Hyeon, Jua, Nanum Myeongjo, Song Myung, Anton). 본문은 시스템 글꼴
- 테스트: Vitest(분석·레이아웃 로직), Playwright 스모크(나중에)

## 접근성 원칙

- 모든 메뉴와 기능을 키보드로 사용. 화면 전환 시 새 화면 제목으로 포커스 이동
- 모션 감소 설정(시스템 + 앱 내 토글)에서 컷인·흔들림을 정적 전환으로
- 빨강 단색 배경 위 글자는 흰색/검정만 사용해 대비 4.5:1 이상
- 예고장 캔버스는 원문을 대체 텍스트로 제공
- 음성 기능은 모두 텍스트로 대신할 수 있음

## 저작권 원칙

페르소나 5의 로고·글꼴·캐릭터·음악·이미지·고유 문구는 쓰지 않는다. 빨강·검정·흰색 대비, 오려 붙인 콜라주 타이포, 사선 레이아웃, 과감한 컷인 같은 스타일 모티브만 가져오고 이름·문구·그림은 새로 만든다.
